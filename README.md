# American Roulette

A self-contained, single-file American Roulette game built with HTML/CSS/JS — no build step, no dependencies.

Open `index.html` in a browser to play.

## Features

- Full American roulette table layout: separate 0 and 00, straight/split/street/corner/six-line/column/dozen/even-money bets
- Real casino-style split/corner/street/six-line hotspots computed from the actual rendered grid, so bet markers always line up
- Spinning wheel animation synced exactly to the resolved winning number
- Adjustable balance (set or top up) and a "repeat last bet" shortcut
- Centered chip markers on every betting spot
